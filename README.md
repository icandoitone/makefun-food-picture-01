# The Noodle Pull

A steaming bowl of tonkotsu ramen for make.fun food-picture-01: glossy
noodles lifted by chopsticks, a jammy soft-boiled egg, chashu pork and
spring onions in warm golden light. One hero dish, shot to make you
hungry at first glance.

`main.py` copies `art.png` to `/output/entry.png` (with a sha256
self-check). The program is deterministic: every run writes identical
bytes.
